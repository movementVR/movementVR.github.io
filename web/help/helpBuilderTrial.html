Builder Guide
Trial Builder

The Trial Builder helps you generate sequences of parameter values for your trial‑varying parameters in a code‑free way. It supports a range of trial structures and sequence types commonly used in motor control and learning research:

  • Ordered sequences – apply a list of values in the order you specify
  • Randomized sequences – shuffle values using simple, weighted, or blocked randomization
  • Linear ramps – gradually change a parameter from a start to an end value across trials
  • Random distributions – draw values from a uniform or normal distribution
Steps for creating trial-by-trial sequences of values
  1. Open the Trial Builder for the desired parameters
    • To open the Trial Builder, follow the steps described in Setting Trial‑Varying Parameters, selecting Trial Builder as the method.
    • This opens a Trial Builder window specific to the selected parameter(s). Here, you will generate a trial-by-trial sequence of parameter values for the parameters selected via the ⚙ icon (in contrast to the Static Builder, the Trial Builder focuses on a single group of parameters).
  2. Left Panel: Manage the list of phases and assign trial types.

    In the Trial Builder, you will first use the Left Panel to divide your experiment into multiple phases — such as baseline, learning, and washout:

    1. Subdivide trials into phases: Organize your experiment into consecutive blocks of trials, called phases.
    2. Assign a trial type to each phase: Each phase is associated with a trial type that defines how parameters behave during that phase. Multiple phases can share the same trial type if they require identical behavior.
  3. Right Panel: Configure trial type settings and parameter value generation.

    For each phase, you will then choose how the parameter values change trial‑by‑trial by defining the sequence type and values in the Right Panel

    1. Define how parameter values behave in each trial type: Specify the method used to generate parameter values—whether they follow a fixed sequence, are randomized, ramp up/down, or adhere to a statistical distribution (this is called the sequence type).
    2. Provide the necessary input values: Enter specific values to control the sequence, such as the list of parameter values, start and end points for ramps, or parameters for statistical distributions.
Example: How do I decide phases and sequence types?

This is an example of how we could design a gradual adaptation paradigm. First, we would open the Trial Builder for the desired perturbation magnitude parameter (e.g. Right Gain Y). Then, we would define the Phases and Trial Types as follows:

  1. Phases:
    • Baseline
    • Early Adaptation
    • Adaptation Plateau
    • Washout
  2. Trial Types:
    • no perturbation (assigned to: Baseline, Washout)
    • gradually increasing (assigned to: Early Adaptation)
    • full perturbation (assigned to: Adaptation Plateau)
  3. Sequence Types:
    • no perturbation = constant value
    • gradually increasing = gradual ramp
    • full perturbation = constant value
  4. Input Values:
    • no perturbation: Constant Value = 0%
    • gradually increasing: Starting Value = 0%, Ending Value = 100%
    • full perturbation: Constant Value = 100%

Note that this parameter- and phase-specific setup is designed for flexibility:

  • Different phases in the experiment can use different sequence types.
  • Each parameter can be defined independently, using its own experimental phases and sequence‑type settings.

For example:

  • you could set the perturbation gain to “Linear Ramp” for the “learning” phase but to “constant” for “baseline” and “washout” phases
  • at the same time, you could randomize target position during “target‑variable” phases but keep it constant during “target‑fixed” phases.
  • the “target‑fixed” and “target‑variable” phases do not have to match the “baseline”, “learning”, and “washout” phases.
Left Panel: Experiment Phases

The left panel is where you organize the experiment into phases. It consists of a list of “phases”, where each row in the list represents one “phase”.

Each “phase” (each row) has the following elements:

  • Trial Type Dropdown

    Each row has a dropdown menu to select the “trial type” for that phase. By default, you see three options: Baseline, Learning, and Washout. Select <add option> in the dropdown to create additional “trial types”.
    Multiple rows (phases) can share the same trial type if needed. For example, you might have two separate phases that both use the “unperturbed” trial type but occur at different times in the experiment, such as pre and post learning.

  • Selecting a Phase and Viewing Parameters

    Click on a phase row in the left panel to select it. This opens the “Trial Type Settings” panel (right panel) for the “trial type” associated with that phase. Note that there is only one “Trial Type Settings” panel for each “trial type”: if two phases share the same trial type, they both link to the same “Trial Type Settings” panel, and any changes will apply to all phases using that trial type.

  • Number of Trials

    Next to the “trial type” dropdown, there is a numeric input field where you set the number of trials in that phase.

  • Adding, Removing, and Reordering Phases

    The Left Panel UIs has buttons to Add, Remove and Drag-to-reorder the experimental phases.

    • use the + button at the top-right of the left panel to add a new phase row
    • each row has a delete button (trash icon to the right): click to remove the phase
    • click-and-drag a row to move it, reordering the phases
Right Panel: Trial Type Settings

The Trial Type Settings Panel (right panel) is where you configure the parameter values for each “trial type” selected in the left panel. You only need to configure a “trial type” once, and any phases using that “trial type” will automatically use the same settings.

The top row of the panel shows the name of the Selected “Trial Type”, and the Sequence Type Dropdown (top-right) – which allows you to choose how parameters will change across trials (details below). The main area of the panel consists of a “parameter input” list, containing repeated instances of the “selected parameter group” (each row is one instance; note that it is possible that you may only have a single item in the list).

Defining trial-by-trial parameter values for the current “trial type” involves two steps:

  1. Select the correct sequence type using the “Sequence Type Dropdown”. This will modify certain aspects of the “parameter input” list.
  2. Fill in the values for each row of the “parameter input” list, in a way that is appropriate to the selected sequence type. You may need to add / remove / reorder rows as needed.

Selecting Sequence Type in the Right Panel

Each Phase Panel features a “Sequence Type” dropdown in its title bar (top right). Use this dropdown to select how parameters will vary across trials in this phase.

Each dropdown option offers a different method for generating the trial-by-trial sequence of parameter values:

  • Deterministic options (predefined values and order, no randomness)
    • Constant values (dropdown = "Constant")

      Parameter values are constant across all trials in this phase. The right panel shows a single row of input fields where you can enter the fixed value for each parameter.

    • Gradual ramp (dropdown = "Linear Interpolation")

      Parameter values change linearly trial-by-trial starting at the start value and ending at the end value you provide. The right panel shows two rows of input fields: one for the start value and one for the end value of each parameter.

    • Ordered sequence (dropdown = "Sequential")

      Parameter values change trial-by-trial according to a predefined list of values, which you define using the right panel. The right panel shows multiple rows of input fields: each row corresponds to a single trial where you can enter the parameter values for that trial. These values are applied sequentially, trial-by-trial, in the order you set. Click “Add Value” at the top-right of the panel to insert new rows. Click-and-drag existing rows to reorder them, or click “Remove” on a row to delete it.

  • Randomized order options (random sampling of predefined values)
    • Random sequence (dropdown = "Random Samples")

      For each trial, parameter values are drawn with replacement from a list of values that you define using the right panel. The right panel shows multiple rows of input fields: each row represents one potential set of parameter values for one trial. Enter each potential set of parameter values on a separate row. Click “Add Value” at the top-right of the panel to insert new rows. Click-and-drag existing rows to reorder them, or click “Remove” on a row to delete it. The order of entries in the list is irrelevant. On each trial, parameter values are selected at random from your list using probability weights specified to the right of each row. Each weight is 1/1 by default (equal probability); weights are normalized automatically (so do not worry if the shown probability values do not add up to one - they will in the game). Values are drawn with replacement, meaning that the same value may appear multiple times before others are used.

    • Blocked random sequence (dropdown = "Blocked Random Samples")

      For each trial, parameter values are drawn without replacement (with block reset) from a list of values that you define using the right panel. The right panel shows multiple rows of input fields: each row represents one potential set of parameter values for one trial. Enter each potential set of parameter values on a separate row. Click “Add Value” at the top-right of the panel to insert new rows. Click-and-drag existing rows to reorder them, or click “Remove” on a row to delete it. The order of entries in the list is irrelevant. On each trial, parameter values are selected at random from your list using equal probability across parameter values that have not yet been drawn. Values are drawn without replacement within each block (block = full list of values): every potential set of parameter values is selected exactly once before any repeats occur; when all values have been used, the block resets (list reshuffles).

  • Random values options (values generated from a probability distribution)
    • Uniform Distribution (dropdown = "Uniform Random Values")

      Parameter values are randomly generated for each trial based on a uniform distribution. You define the minimum and maximum bounds, and all values within this range have equal probability. The right panel shows two rows of input fields corresponding to these bounds.

    • Normal Distribution (dropdown = "Normal Random Values")

      Parameter values are randomly generated for each trial based on a normal distribution. You define the mean and variance of the distribution. The right panel shows two rows of input fields corresponding to these parameters.

Defining the Parameter Input List in the Right Panel

The main content of the Right Panel shows the "Sequence Values" - a form-like interface where you can set the value of the parameters. Each row replicates the format of the parameter group as displayed in the Static Builder, and it represents a different quantity depending on the selected Sequence Type:

  1. Constant, Sequential, Random Samples, Blocked Random Samples: each row represents the value for the parameter(s) for a single trial (each trial will take value from one of the rows)
  2. Linear Interpolation: there are two rows corresponding to the first and last value in the linear ramp (trials will ramp between these values)
  3. Uniform Random Values: there are two rows corresponding to the Lower and Upper limits of the Uniform Distribution
  4. Normal Random Values: there are two rows corresponding to the Mean and Variance of the Normal Distribution

For Sequence Type = Sequential, Random Samples, or Blocked Random Samples, the Right Panel allows you to Add and Remove rows and Drag to reorder them:

  1. use the + button at the top-right of the right panel to add a new row with parameter value
  2. each row has a delete button (trash icon to the right): click to remove this row of parameter value
  3. click-and-drag a row to move it, reordering the sequence of parameter values
Detailed Implementation Example for Gain Visuomotor Adaptation Paradigm

In this example, we are working with a gain visuomotor adaptation paradigm using the parameter gainY to control visual perturbation. Here, the visual perturbation slows the appearance of the right hand:

  • gain = 1: No perturbation (the hand moves normally).
  • gain > 1: The hand appears slower than normal.

Our experimental design includes:

  • 20 Baseline (BL) Trials without perturbation
  • 100 Trials with gradual introduction of perturbation
  • 50 Trials at maximum perturbation value (gain = 1.5)
  • 40 Washout Trials returning to no perturbation

We can structure the experiment as follows:

  1. Phases (Left Panel):
    • Baseline (20 trials; Trial Type: No Perturbation)
    • Initial Adaptation (100 trials; Trial Type: Gradually Increasing)
    • Adaptation Plateau (50 trials; Trial Type: Full Perturbation)
    • Washout (40 trials; Trial Type: No Perturbation)
  2. Trial Types (Left Panel):
    • No Perturbation: Used in the Baseline and Washout phases.
    • Gradually Increasing: Used in the Initial Adaptation phase.
    • Full Perturbation: Used in the Adaptation Plateau phase.
  3. Sequence Type (Right Panel):
    • No Perturbation: Set as Constant (same value across trials).
    • Gradually Increasing: Set as Ramp (linear change from start to end value).
    • Full Perturbation: Set as Constant (fixed maximum perturbation value).
  4. Values (Right Panel):
    • No Perturbation: Constant value of 1.
    • Gradually Increasing: Ramp from 1 (start) to 1.5 (end).
    • Full Perturbation: Constant value of 1.5.

A Different Implementation Example via Images

In this example, we will create a Trial Schedule for the Right Hand Y Gain using the Trial Builder. Other gain parameters (X, Z, left hand gain) will remain constant and set by the Static Builder.

We will implement a schedule with five phases:

  • Baseline – 30 trials, gain = 0
  • Learning with Gradual Perturbation – 50 trials, gain ramps linearly from 0 to -50
  • Catch – 5 trials, gain = 0
  • Plateau of Learning – 30 trials, gain = -50
  • Washout – 60 trials, gain = 0

As discussed, the first step is to assign the same Trial Type to phases that have the same gain. Here, we will use the following trial types:

  • Baseline Trial: Any trial where the gain is 0
    (includes Baseline, Catch, and Washout phases)
  • Learning Trial: Trials in the gradual perturbation phase
    (gain ramps from 0 to -50)
  • Plateau Trial: Trials in the plateau phase
    (gain held constant at -50)

Hence, we will define the following trial phases in the Trial Builder:

  1. Baseline Trial — 30 trials, gain = 0
  2. Learning Trial — 50 trials, gain ramp from 0 to -50
  3. Baseline Trial — 5 trials (Catch), gain = 0
  4. Plateau Trial — 30 trials, gain = -50
  5. Baseline Trial — 60 trials (Washout), gain = 0
