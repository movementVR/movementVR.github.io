Builder Guide
Parameter Catalog

The Parameter Catalog provides a searchable reference table listing all parameters available across the Builder interface. It is useful for verifying parameter labels, checking where parameters appear in the UI, and preparing valid CSV files.

Overview

Click Parameter Catalog in the Session Manager panel of the Main Builder page to launch this table.

This opens the Parameter Catalog as a popup window:

Table Columns
  • Code Name: Internal identifier used in CSV files (scriptName,paramName format).
  • UI Location: Builder window and tab where the parameter is edited (e.g., location in main builder grid → tab in static builder).
    • For View Mode = All Builder Locations, each location in the Builder is presented on a separate row
    • For View Mode = Unique Parameters, different locations are separated by | and shown in the same row
  • Display Label: How the parameter is shown to the user in the Builder interface (e.g., Size [m]: → Width).
  • Type: Input type and any constraints (e.g., number (min=0, max=1) or checkbox (values: TRUE, FALSE)).
  • Description: Description of the parameter group this parameter is part of. You can click on the description to expand it below the row.
Table Controls

View Modes

The toggle buttons above the table control whether duplicate entries are shown:

  • All Builder Locations: Shows each parameter as many times as it appears in the Builder. This includes duplicates when the same parameter is editable from multiple buttons or links.
  • Unique Parameters: Shows each parameter only once, with all its Builder locations merged into a single line.

Search Bar & Sortable Column Headers

The Search Bar above the table allows you to search text in any of the columns

You can also click on each column header to sort the list in ascending/descending order according to that column.

Page Navigation

The "Show # entries" Dropdown at the top-right lets you choose how many rows to display at once.

The Page Navigation Buttons at the bottom right allow you to move between pages of results.

Expandable Text & Resizable Columns

If a text entry is too long to fit in the visible space, you can view the full content in three ways:

  • Hover your mouse over the text to display a tooltip with the full content.
  • Click the textto expand the row and show the full text below the current content.
  • Drag the column border to resize the columns and reveal more text.
Exporting as CSV

Click the Download View button at the bottom-right to export the current view to a .csv file.

This file contains the same columns and rows currently shown in the table - the format and number of rows depend on your "View Mode" Selection (rows show either all locations or unique parameters).

Note: There is also a Download Template button to download a CSV template for preparing CSV files with parameter values to be imported. See File Import → File Format for details.
