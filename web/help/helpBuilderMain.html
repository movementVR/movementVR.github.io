Builder Guide
Main Builder Interface

To start, select the Builder tab in the navigation menu. This will open the Main Builder interface - your starting point for designing tasks in MovementVR.

Main Grid View

The Main Builder Interface provides you with a visual representation of the different task components and game objects, and the rules and conditions that guide trial behavior and transitions. You will click on game objects or buttons labeled with task components to open dedicated interfaces where you can edit their associated parameters.

The interface for the Main Builder page is organized as a grid, where:

  • Each row: corresponds to a different game object or task component.
  • Each column: represents a sequential “phase” within a trial.
  • Each cell: indicates whether a given object is present or active during a specific trial phase. Colored horizontal bars span across the relevant phases for each object.
Game Objects and Task Components (Rows)

The left side of the grid lists the main elements involved in the task:

  • Feedback: Objects and effects that deliver success or failure feedback.
  • Bird: A virtual, animated bird that is perched on the target.
  • Target: The goal object to reach; includes both functional and visual targets.
  • Plate: The object participants lift as part of the motor task.
  • Hand Home: The home position for the participant’s hand(s) and criteria to start the trial
  • Hands & Gain: Hand tracking and recording, and adaptation perturbation
  • Text Prompts: Instructions or other prompts shown to participants at different phases.

Clicking on a row lets you edit the properties associated with that game object or task component.

Trial Flow (Columns)

The top of the grid shows the Trial Flow, with columns representing distinct phases that occur in order during each trial:

  1. Intertrial: Programmed time interval between two trials (short pause).
  2. Return Home: Participant returns hands to the designated start position.
  3. Start Lift: Plate appears; system waits for participant to make contact with it to start the lift.
  4. Execute Lift: Participant lifts the plate toward the target.
  5. Feedback: Visual or auditory feedback is given after lift completion.
  6. Break: Optional rest phase shown on selected trials.

Click Trial Flow or any phase name at the top of grid to configure when and how phases change during a trial (e.g., timing, success/failure conditions, etc.).

Quick Links

In addition to the primary grid, we provide Quick Links (located to the right of the grid) that open commonly used parameter sets grouped by experimental topic:

  • Reaching Task: home & starting position, target position and success criteria...
  • Motor Adaptation: perturbation magnitude and schedule
  • Reinforcement: feedback visuals/sounds/effects to convey success or failure
  • Paradigm: overall paradigm start & end (messages/delays), trial number display, paradigm phases...
  • Kinematics: hand tracking and data recording options
Session Manager

The Session Manager (located to the right of the grid below Quick Links) provides tools to help you configure and reuse parameter setups in the Builder:

  • Upload Parameters: prompts you to upload a .csv file and imports all parameter values in the file to the Builder. See the File Import section of this Builder Guide for details.
  • Save / Load Session: opens options to save your current Builder Session setup for future use, or load a previously saved session to resume or repeat it. Expand Save / Load Session below for details.
  • Parameter Catalog: opens a searchable table listing all Builder parameters. See Parameter Catalog section of this Builder Guide for details.
Save / Load Session

Click Save / Load Session in the Session Manager to store or load the complete configuration for a Builder session.

The configuration includes:

  • Parameter Values: values for all parameters, both constant and trial-by-trial sequences
  • Input Sources: whether each parameter is set using Static Builder, Trial Builder, or File
  • Trial Builder Configuration: for all parameters with Input Source = Trial Builder, it stores the complete configuration of the panels.
    • This differs from the "Parameter Values" described above, as it stores how values are generated (e.g., experimental phases, lists of values, probability distribution parameters, randomization rules...), rather than the actual values drawn or generated.
    • This allows you to reuse the same randomization or sequence generation rules while still allowing the actual random values or random order to vary across participants.

The session configuration can be stored in internal memory or exported to .json file (recommended).

Loading a configuration replaces all content in the Builder with the stored content.

Download & Help Buttons

Below the main grid, you can find Download and Help buttons:

  • Download: after completing your configuration, click Download to export all parameter values to a .csv file used at runtime on the headset:
    • The .csv file contains both static and trial-varying parameters and is used by the MovementVR application to apply your configured task structure during runtime.
    • It must be transferred to the headset for use - see Application for instructions.
    • The format of the file is desribed in the File Import → File Format
  • Help: all Builder windows include a Help button at the bottom left. Clicking this button opens a contextual help popup in the current interface with quick tips and explanations of key interface elements. Note that contextual help is less detailed than the full Builder Guide.
How do I locate the parameter I want to edit?

If you are unsure whether a specific setting can be changed or where to find it in the Builder, use the Parameter Catalog. This is a searchable list of every parameter in MovementVR, with information including:

  • Where to find the parameter in the Builder
  • Description of what the parameter customizes in the game
  • Type of value - number, checkbox...- and notes on coordinate system, units...
  • Internal identifier that you can use to import the parameter from .csv file

To access the Parameter Catalog, click Parameter Catalog in the Session Manager panel of the Main Builder. For more information, see Parameter Catalog Help.
