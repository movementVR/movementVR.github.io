Documentation: startScript.cs

1. Overview

startScript coordinates the initialization sequence for a MovementVR experimental session. It initializes key components (e.g., setup, tracking, messaging, plate and grape objects), handles any delay before the experiment begins, and activates the trial execution logic. This script runs once at the beginning and then disables itself.

2. Functional Blocks

Startup Sequence

  • In Start(), initializes and calls startup on all major subsystems: setup, tracking, plate, targets, and messages.
  • Displays the "start" message to the user.

Delayed Start

  • Waits for experimentStartTimeDelay seconds before activating trial logic.
  • Completes setup with delayed calibration (e.g., headset reference), enables gameplay triggers, hides the start message, and enables trialScript.

Component Interactions

  • Interacts with handsAndSaveScript, setupScript, messagesScript, plateAndGrapeScript, and trialScript.

void Start() { setupScriptVar = GetComponentInParent<setupScript>(true); handsAndSaveScriptVar = GetComponentInParent<handsAndSaveScript>(true); messagesScriptVar = GetComponentInChildren<messagesScript>(true); GetComponentInChildren<plateAndGrapeScript>(true).startup(); GetComponentInChildren<taskWorkspaceScript>(true).startup(); setupScriptVar.startup(); handsAndSaveScriptVar.startup(); GetComponentInChildren<plateScript>(true).startup(); GetComponentInChildren<targetScript>(true).startup(); foreach (handTriggerScript s in GetComponentsInChildren<handTriggerScript>(true)) { s.startup(); } setupScriptVar.updateObjectProperties(true, false); messagesScriptVar.messageDisplay("start", true); StartCoroutine(delayedStartup()); }

delayedStartup()

private IEnumerator delayedStartup() { experimentStartTime = DateTime.Now; yield return new WaitUntil(() => (DateTime.Now - experimentStartTime).TotalSeconds >= experimentStartTimeDelay); handsAndSaveScriptVar.delayedSetup(); setupScriptVar.updateObjectProperties(false, true); handsAndSaveScriptVar.infoSave(); transform.Find("PlateAndGrape/PlateStand").gameObject.SetActive(true); transform.Find("Triggers/Target").gameObject.SetActive(true); transform.Find("Triggers/GameareaBoundary").gameObject.SetActive(true); messagesScriptVar.messageDisplay("start", false); GetComponentInParent<trialScript>().enabled = true; enabled = false; }
