Documentation: handTriggerScript.cs

1. Overview

handTriggerScript is a base class for detecting hand-trigger interactions in a VR motor learning task. It monitors when either the left or right hand enters or exits a trigger volume and determines if all (or specific) hand conditions are met for progressing the experiment. It is designed to be extended by child classes like handsStartingPositionScript and handGainResetScript.

2. Functional Blocks

Initialization

  • startup(): Sets references to key scripts in the task hierarchy and calls a child-implemented individualStartup().
  • OnEnable(): Sets the initial condition depending on whether the hand is expected to be inside or outside the trigger volume. Automatically considers inactive hands as condition met.

Trigger Events

  • OnTriggerStay(): Updates state when a relevant hand collider is inside the trigger volume.
  • OnTriggerExit(): Updates state when a hand leaves the trigger volume.

Condition Checking

  • allHandConditionsMet(): Returns true if all active hand triggers have met their condition.
  • oneHandConditionsMet(bool): Returns true if all active triggers for the specified hand have met their condition.

Collision Relevance

  • relevantCollision(Collider): Uses hand tracking system to determine if a collision is from the correct hand and body part.
  • inactiveHand(): Returns true if the hand assigned to this trigger is not active in the current trial.

Override Hooks

Designed for extension: child classes should implement individualStartup() and changeState().

Class Variables

Start and Enable

void Start() { // Unused in base class } public void startup() { trialScriptVar = transform.Find("/Task").GetComponent<trialScript>(); setupScriptVar = transform.Find("/Task").GetComponent<setupScript>(); handsAndSaveScriptVar = transform.Find("/Task").GetComponent<handsAndSaveScript>(); individualStartup(); } private void OnEnable() { changeState(!targetTypeInsideOf || inactiveHand(), true); }

Trigger Events

private void OnTriggerStay(Collider other) { if (isActiveAndEnabled && relevantCollision(other)) { changeState(targetTypeInsideOf, false); } } private void OnTriggerExit(Collider other) { if (isActiveAndEnabled && relevantCollision(other)) { changeState(!targetTypeInsideOf, false); } }

Condition Checks

protected bool allHandConditionsMet() { foreach (handTriggerScript s in handTriggerScriptVars) { if (s.isActiveAndEnabled && !s.handConditionMet) return false; } return true; } protected bool oneHandConditionsMet(bool leftHandFlag) { foreach (handTriggerScript s in handTriggerScriptVars) { if (s.targetHandLeft == leftHandFlag && s.isActiveAndEnabled && !s.handConditionMet) return false; } return true; }

Utility Methods

bool relevantCollision(Collider other) { return handsAndSaveScriptVar.isCollisionWithHand(other, targetHandLeft, targetTypeInsideOf, triggerType); } protected bool inactiveHand() { return (targetHandLeft && !handsAndSaveScriptVar.leftHandActiveFlag) || (!targetHandLeft && !handsAndSaveScriptVar.rightHandActiveFlag); }
