Documentation: trialScript.cs

1. Overview

The trialScript class is the central trial manager for MovementVR. It coordinates stage-based trial progression, gain perturbations, target bird behavior, and success/failure detection. It integrates inputs from multiple subsystems (hands, plate, workspace, messages, etc.) and governs experiment flow across trials and phases.

2. Functional Blocks

Trial Initialization

  • Start(): Loads references to all key components and initializes gain logic and bird display.
  • autoGain(): Computes gains per trial based on experimental paradigm (baseline, gradual, full perturbation, washout).

Stage Progression (Update)

  • Update(): Advances the trial through stages 1 to 6 based on time, user interaction, or task state.
  • Each stage transition is handled via dedicated toStageN() methods.

Gain Control

  • updateGain(): Smoothly transitions hand gain values over time when triggered.
  • applyPerturbation(): Applies gain offsets to hand position in real time based on origin and gain vector.
  • computeGainOrigin(): Determines the coordinate origin for gain computations based on various criteria (fixed position, home, contact).

Trial Lifecycle and Feedback

  • nextTrial(): Advances to next trial, updates parameters, and refreshes the experiment state.
  • changeBirdAtTarget(): Selects and spawns a bird based on species logic and user-defined trial criteria.

Interfaces

  • trialStageTrigger(): External trigger to signal when the task should advance stage (e.g., after contact or collision).
  • updateGainOrigin(): Coroutine to interpolate gain origin smoothly over time.

3. Full Technical Details

Key Concepts

  • Trial Stages: Trial execution is split into 6 stages, each with a specific logic path (base delay, hand repositioning, lift, result, break).
  • Gain Application: Per-trial and within-trial spatial perturbations are applied to the hand using a vector gain multiplier from a configurable origin.
  • Bird Display: Birds act as animated visual feedback at the target, and their appearance can change based on trial outcomes or phases.
