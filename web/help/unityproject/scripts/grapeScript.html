Documentation: grapeScript.cs

1. Overview

The grapeScript class manages interaction behavior for individual grapes in a Unity VR motor learning experiment. It determines how grapes respond to collisions, particularly with hands or boundaries. It allows certain collisions (like those with the participant's virtual hands) to be temporarily ignored and also notifies the trial controller when a grape falls out of bounds.

2. Functional Blocks

Initialization

Links to the parent trialScript and handsAndSaveScript to handle stage control and hand-collision logic.

Collision Handling

  • If grapeAlwaysIgnoreHands is true and the collision is with a hand, ignore future collisions with that hand.
  • If the grape hits the game area boundary, the trial is marked as failed by calling trialStageTrigger(-3).

Cleanup on Disable

When the grape is disabled, previously ignored hand collisions are re-enabled via resetIgnoreCollision().

Collision Handling

void OnCollisionEnter(Collision collision) { // Ignore hand collision if applicable if (grapeAlwaysIgnoreHands && headHandsScriptObj.isCollisionWithHands(collision.collider)) { ignoredColliders.Add(collision.collider); foreach (Collider plateCollider in GetComponentsInChildren<Collider>()) { Physics.IgnoreCollision(collision.collider, plateCollider); } } // If grape hits game area boundary, trigger trial failure if (collision.transform.parent.name == "GameareaBoundary") { trialScriptVar.trialStageTrigger(-3); } }

OnDisable

private void OnDisable() { resetIgnoreCollision(); }

Reset Ignored Collisions

public void resetIgnoreCollision() { foreach (Collider ignoredCollider in ignoredColliders) { if (ignoredCollider != null) { foreach (Collider plateCollider in GetComponentsInChildren<Collider>()) { if (plateCollider != null) { Physics.IgnoreCollision(ignoredCollider, plateCollider, false); } } } } }
