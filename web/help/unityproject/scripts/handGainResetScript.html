Documentation: handGainResetScript.cs

1. Overview

The handGainResetScript class is a specialized trigger script in Unity, derived from handTriggerScript. It is used to detect hand-based conditions that trigger a gain reset in a motor learning trial. When all required hand conditions are met, it starts a coroutine to reset the gain using trialScriptVar.updateGain().

2. Functional Blocks

Inheritance and Purpose

Inherits from handTriggerScript. Used to define a hand trigger of type gainReset located under /Task/Triggers/GainReset.

individualStartup()

Overrides the base method to:

  • Set the trigger type to "gainReset".
  • Initialize the list of hand trigger scripts by finding them under the expected path.

changeState()

Overrides the base method to:

  • Set handConditionMet based on the given condition.
  • If all hands meet the condition and it’s not during OnEnable, call trialScriptVar.updateGain() as a coroutine.

protected override void individualStartup() { triggerType = "gainReset"; handTriggerScriptVars = transform.Find("/Task/Triggers/GainReset") .GetComponentsInChildren<handGainResetScript>(true); }

changeState()

protected override void changeState(bool conditionMet, bool calledFromOnEnable) { handConditionMet = conditionMet; if (conditionMet && allHandConditionsMet() && !calledFromOnEnable) { StartCoroutine(trialScriptVar.updateGain()); } }
