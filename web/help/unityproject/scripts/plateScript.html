Documentation: plateScript.cs

1. Overview

The plateScript class manages the logic tied to the VR plate used in a motor learning trial. It monitors tilt angle for success criteria and handles key collision events. This includes detecting contact from the hand to start the reaching phase and triggering a failure if the plate collides with the game area boundary.

2. Functional Blocks

Initialization

  • startup() connects the script to the parent trialScript and handsAndSaveScript components.

Plate Tilt Evaluation

  • plateTooTilted() checks if the plate's tilt along any axis exceeds allowable thresholds for success.

Collision Logic

  • OnCollisionEnter() detects the first contact with the hand (to progress the trial) and collisions with boundaries (to trigger failure).

plateTooTilted()

public bool plateTooTilted(float maxTiltForSuccessX, float maxTiltForSuccessY, float maxTiltForSuccessZ) { float plateAngleX = transform.parent.localEulerAngles.x; if (plateAngleX > 180) plateAngleX -= 360; float plateAngleY = transform.parent.localEulerAngles.y; if (plateAngleY > 180) plateAngleY -= 360; float plateAngleZ = transform.parent.localEulerAngles.z; if (plateAngleZ > 180) plateAngleZ -= 360; return (Mathf.Abs(plateAngleX) > maxTiltForSuccessX || Mathf.Abs(plateAngleY) > maxTiltForSuccessY || Mathf.Abs(plateAngleZ) > maxTiltForSuccessZ); }

OnCollisionEnter()

void OnCollisionEnter(Collision collision) { if (waitingForHandContactFlag && handsAndSaveScriptVar.isCollisionWithHands(collision.collider)) { trialScriptVar.trialStageTrigger(2); // Hand contacted plate } else if (collision.transform.parent.name == "GameareaBoundary") { trialScriptVar.trialStageTrigger(-3); // Failure: plate left bounds } }
