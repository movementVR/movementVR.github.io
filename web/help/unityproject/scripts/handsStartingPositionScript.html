Documentation: handsStartingPositionScript.cs

1. Overview

handsStartingPositionScript is a trigger script in Unity used for detecting whether a user's virtual hands are within a predefined "starting position" zone at the beginning of a trial. This class changes the color of a visual boundary mesh to indicate success or failure and communicates readiness to the trial controller. It inherits from handTriggerScript.

2. Functional Blocks

Startup Logic

  • Sets the trigger type to "handStarting".
  • Finds and stores references to all sibling handsStartingPositionScript triggers.
  • Chooses the correct mesh (left or right) to control based on hand.

State Change Handling

  • changeState(): Updates the internal state based on whether the condition was met, triggers the visual update, and signals the trial controller to begin (stage 1) or stay at waiting (stage 0).

Mesh Feedback

  • setMeshState(): Changes the color of the mesh to visually indicate whether the starting hand condition has been met.

protected override void changeState(bool conditionMet, bool calledFromOnEnable) { handConditionMet = conditionMet; setMeshState(); if (conditionMet && allHandConditionsMet() && !calledFromOnEnable) { trialScriptVar.trialStageTrigger(1); } else { trialScriptVar.trialStageTrigger(0); } }

setMeshState()

void setMeshState() { Renderer meshRenderer = meshParentTransform.GetComponentInChildren<Renderer>(false); if (meshRenderer != null) { bool relevantConditionsMet = (setupScriptVar.handStartingBoundMeshColorHandsCoupled && allHandConditionsMet()) || (!setupScriptVar.handStartingBoundMeshColorHandsCoupled && oneHandConditionsMet(targetHandLeft)); if (relevantConditionsMet) { meshRenderer.material.color = new Color( setupScriptVar.handStartingBoundMeshColorSuccessR, setupScriptVar.handStartingBoundMeshColorSuccessG, setupScriptVar.handStartingBoundMeshColorSuccessB, setupScriptVar.handStartingBoundMeshColorSuccessAlpha ); } else { meshRenderer.material.color = new Color( setupScriptVar.handStartingBoundMeshColorUnsuccessR, setupScriptVar.handStartingBoundMeshColorUnsuccessG, setupScriptVar.handStartingBoundMeshColorUnsuccessB, setupScriptVar.handStartingBoundMeshColorUnsuccessAlpha ); } } }
