Documentation: setupScript.cs

Overview

The setupScript class handles all configuration and initialization of the experimental environment. It reads trial-independent inputs, sets up the physical layout (e.g., plate, workspace, target), defines interaction rules (e.g., starting bounds, gain reset regions), and updates trial-dependent features each trial.

Main Responsibilities

  • Configure starting positions for hands and plate
  • Initialize plate, grape, and target properties
  • Manage workspace and game boundaries
  • Configure triggers for gain updates and trial progression
  • Set up and update messages shown during the experiment
  • Set up visuals and colliders for all bounds and game elements
  • Store experiment-wide parameters

Inputs from File

These fields define the configurable experiment parameters, including spatial bounds, shapes, materials, visual settings, and message behavior.

  • Plate/Grape/Target: position, size, mass, drag, colliders
  • Workspace and Boundaries: shape (cube/sphere), sizes, and auto-alignment options
  • Hand starting bounds: "inside" and "outside" bounds, shape and trigger settings
  • Gain reset bounds: conditions for adaptation update trigger
  • Target mesh and success region: size/position/shape + automated options
  • Target birds: species-specific scale and position
  • Trial messages: per-state font, position, color, type, and rotation
  • Audio: success/fail bird sounds and background levels

Initialization Functions

void Start()

Empty default Start; setup happens in startup().

void startup()

Loads files and enables script logic.

updateObjectProperties()

This is the main method that applies configuration during initialization and optionally each trial. It sets transforms, physics materials, visuals, and links collider-trigger logic.

  • initialSetup: called once at startup
  • delayedSetup: optional, post-headset calibration

Visual and Message Handling

The script configures a number of on-screen messages displayed during different trial stages: start, end, success, fail1-fail5, break, base, lift, contact, etc.

  • Each has font size, color, background color, position, offset, rotation, and type (cartoon, rectangle)
  • Text uses TextMeshPro
  • Colors and positions are defined relative to headset origin

Hand Bounds & Gain Triggers

Configures the collider volumes for hand position triggers, both for showing the plate and resetting gain. These include both inside-of and outside-of bounds, and can auto-align to plate or be manually specified.

Target Configuration

Target and perch configuration includes collider size, mesh shape/size, perch position, and visual mesh logic. Target mesh size can be computed dynamically (e.g., platePlusTarget) or entered manually.

Bird Configuration

Applies scale and position to each individual bird prefab used in the experiment.

Friction Settings

Applies friction coefficients (static/dynamic) for plate–hand and plate–grape contact, including physics material behavior.

Setup Script

This script is responsible for configuring and updating various parameters used throughout the MovementVR experiment. It manages initial setup, trial-by-trial updates, workspace configuration, and the positioning of key elements like the plate, grape, hands, and target birds.

Configuration from Files

  • default.csv: Loads default parameter values for the experiment using reflection on the class hierarchy.
  • parameters.csv: Loads general experiment parameters with error-handling and debugging.
  • trials.csv: Loads trial-by-trial parameter variations and flags which components (plate, target, etc.) need updates per trial.

Audio Setup

Loads audio files for success and failure feedback using UnityWebRequest. The expected filenames are successSound.wav and failSound.wav in the persistent data path.

Object Update Flags

Function setTrialFlags marks which game objects (e.g., plate, grape, friction, messages, bounds) need updating based on variables found in the trial csv. These flags optimize per-trial update performance.

Workspace Boundaries

The setOutsideOfBound method configures inside/outside triggers for hand positioning or gain reset. It adjusts colliders dynamically based on shape (cube/sphere), position, direction, and trial flags.

Public Query Methods

  • getTargetBirdPosition – Returns the 3D position for the target bird.
  • getTargetBirdRotation – Returns the target bird's orientation as a quaternion.
