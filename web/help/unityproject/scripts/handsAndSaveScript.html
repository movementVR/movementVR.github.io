Documentation: handsAndSaveScript.cs

1. Overview

The handsAndSaveScript class manages VR hand tracking, headset pose tracking, and detailed per-frame data logging (kinematics and transforms) in motor learning experiments. It monitors whether hands are tracked and whether they are in contact or penetrating other objects (e.g., a plate). It also supports saving kinematic data, perturbation offsets, and collider configurations for further analysis.

2. Functional Blocks

Initialization and Setup

  • startup(): Prepares all relevant components, sets up what data to save, and creates a timestamped save folder.
  • delayedSetup(): Used to re-capture initial headset transform later if needed.

Update Loop

Monitors if the user’s hands are being tracked or are penetrating the plate. If so, sets the plate to be kinematic (non-movable) to prevent unrealistic behavior. Also performs data saving if enabled.

Saving Logic

  • infoSave(): Saves headset initial position and rotation (and optionally other metadata).
  • changeTrialStage(int, int): Records the current trial and stage, encoded as float (e.g., 1.2 = Trial 1, Stage 2).

Hand State & Tracking

  • updateHandsState(): Updates hand tracking and activity flags.
  • isCollisionWithHands(Collider) and isCollisionWithHand(...): Determine if a given collider belongs to the hand(s).

Collider Configuration

  • setWristsTriggerColliders(): Updates wrist collider properties based on task-defined triggers.

Virtual Methods for Extension

  • rigSetup(), leftNotTracking(), additionalFrameSave(), etc.: Empty base methods designed for child-class overrides.

Data Saving in Update

void Update() { // If hand tracking fails, freeze plate if ((actualLeftHandTrackingFlag && leftNotTracking()) || ...) { plateAndGrapeScriptVar.setPlateKinematic(true); handsNotVisibleOrPenetrating = true; } else { if (handsNotVisibleOrPenetrating && !plateAndGrapeScriptVar.getPlatePenetration(...)) { plateAndGrapeScriptVar.setPlateKinematic(false); handsNotVisibleOrPenetrating = false; } } // Data logging if (saveBasicData) { string fileName = folderName + "\\frame" + frame++ + DateTime.Now.ToString("_yyyy_MM_dd_HH_mm_ss_FFF") + ".bin"; using (BinaryWriter binWriter = new BinaryWriter(File.Open(fileName, FileMode.Create))) { binWriter.Write(trialNumberAndStage); binWriter.Write((float)(DateTime.Now - startTime).TotalSeconds); if (savePerturbationOffset) { binWriter.Write(leftHandOffset.x); // etc. } foreach (Transform t in transformsToBeSaved) { binWriter.Write(t.position.x); // etc. } additionalFrameSave(binWriter); } } }

Wrists Trigger Colliders

public void setWristsTriggerColliders(string hand, string triggerType, Collider taskCollider) { Transform wrist = hand == "left" ? leftWrist : rightWrist; int compIndex = colliderNumber(triggerType); BoxCollider box = wrist.GetComponents<BoxCollider>()[compIndex]; SphereCollider sphere = wrist.GetComponents<SphereCollider>()[compIndex]; if (taskCollider is SphereCollider) { box.enabled = false; sphere.enabled = true; sphere.radius = ((SphereCollider)taskCollider).radius; } else { box.enabled = true; sphere.enabled = false; box.size = ((BoxCollider)taskCollider).size; } if (hand == "left") leftWristCollider[compIndex] = sphere; else rightWristCollider[compIndex] = sphere; }
