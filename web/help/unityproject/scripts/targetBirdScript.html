Documentation: targetBirdScript.cs

1. Overview

targetBirdScript controls the bird animations, sounds, and motion behavior associated with a target in MovementVR. It handles entry and exit animations, randomized idle animations, and physical bird movements such as takeoff, flight, and landing. The script is used to display a responsive and animated bird on target objects, optionally triggered by trial events.

2. Functional Blocks

Initialization

  • Awake(): Caches the parent setupScript.
  • Start(): Loads audio clips and volumes from setupScript and initializes sound sources.

Lifecycle Control

  • OnEnable(): Positions the bird, sets animation state, and begins idle or flight behavior based on entryAnimation.
  • OnDisable(): Stops motion, resets transform, and plays particle effects.

Flight State Machine

  • Update(): Drives the main loop that switches between ground, takeoff, flight, and landing.
  • State transitions are managed via toStage0() to toStage3().

Motion and Animation

  • motionGround(): Periodically triggers random idle animations.
  • motionTakeoff(), motionFlying(), motionLanding(): Move the bird and control flight direction and smooth landings.

Feedback

  • Sing(bool success): Triggers a chirp or fail sound with an accompanying animation.
  • PlaySong(): Plays the currently selected sound.

void Awake() { setupScriptVar = GetComponentInParent<setupScript>(); } void Start() { birdSounds = GetComponents<AudioSource>(); var setup = GetComponentInParent<setupScript>(); if (setup.successSound != null) { birdSounds[0].clip = setup.successSound; birdSounds[1].clip = setup.successSound; } if (setup.failSound != null) { birdSounds[2].clip = setup.failSound; } for (int i = 0; i < 3; i++) { birdSounds[i].volume = setup.targetBirdVolume; } }

OnEnable()

void OnEnable() { transform.parent.localPosition = setupScriptVar.getTargetBirdPosition(); transform.parent.localRotation = setupScriptVar.getTargetBirdRotation(); animator = GetComponent<Animator>(); birdTakeoffFlag = false; originalPosition = transform.localPosition; originalRotation = transform.localEulerAngles; targetPosition = transform.localPosition; globalTargetPosition = transform.position; targetRotation = transform.localEulerAngles; timeInAnimation = Random.Range(groundAnimationMinDuration, groundAnimationMaxDuration); animationStartTime = System.DateTime.Now; stageStartTime = System.DateTime.Now; if (entryAnimation == "landing") { flightStage = 2; stageStartRotation = transform.localRotation; animator.applyRootMotion = false; animator.SetBool("flying", true); transform.position += birdAppearanceOffset; rotationDuration = 0; } else if (entryAnimation == "appear") { flightStage = 0; animator.applyRootMotion = true; animator.SetBool("flying", false); } GetComponent<ParticleSystem>().Play(); }

disableBird() and OnDisable()

public void disableBird() { if (exitAnimation == "takeoff") { stageStartTime = DateTime.Now; birdTakeoffFlag = true; } else if (exitAnimation == "disappear") { enabled = false; } } void OnDisable() { GetComponent<ParticleSystem>().Play(); var rb = GetComponent<Rigidbody>(); rb.velocity = Vector3.zero; rb.angularVelocity = Vector3.zero; rb.isKinematic = true; transform.localPosition = originalPosition; transform.localEulerAngles = originalRotation; rb.isKinematic = false; rb.drag = 1; }

Flight State Machine: Update() and Transitions

void Update() { switch (flightStage) { case 0: motionGround(); toStage1(); break; case 1: motionTakeoff(); toStage2(); break; case 2: motionFlying(); toStage3(); break; case 3: motionLanding(); toStage0(); break; } }
