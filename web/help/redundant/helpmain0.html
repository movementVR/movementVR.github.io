MovementVR
MovementVR is a platform designed to make it easy to create and run motor learning experiments in Virtual Reality — no coding required. You can design your experiment using a graphical interface, run it on a standalone VR headset, and analyze the collected data with provided tools. This guide will walk you through each step: understanding the VR motor task (MovementVR Task), designing your own experiment using the Builder, running it in the VR App, and exporting or analyzing the data with the Analyzer.

MovementVR Task
Task Elements
  • Plate & Grape: The object participants lift each trial. Physics-based interaction allows natural grasp and movement. If it tilts or falls, the grape drops.
  • Target: The goal location for the plate. It can change color to indicate success/failure and includes a visible mesh that defines feedback and trial conditions.
  • Hand Home: Starting position for each hand, defined by location and a "no-hand" zone to avoid premature interaction.
  • Bird & Perch: An animated bird sits at the target. Its species, sound, and behavior provide outcome-linked feedback.
  • Feedback Messages: Cartoons and sounds show success or failure after each trial.
  • Hands: Real-time tracked, articulated VR hands with 19 bones for natural interaction.
  • Workspace: The bounded area within which the plate must stay. Exiting ends the trial as a failure.
  • Text & UI: Instructional messages, trial number, and visual elements support user guidance.
  • Background: A medieval-style immersive garden and port setting with ambient birds and scenery.
Trial Phases
  • Intertrial: Pause between trials.
  • Home Position: Hands return to defined start zone.
  • Plate Contact: User initiates lift by touching the plate.
  • Plate Lift: Active lifting phase toward the target.
  • Feedback: Outcome shown via color, animation, or cartoon.
  • Break: Optional rest between trials.
Success and Failure Criteria
  • Success: Plate center reaches target zone, remains within for required duration, and stays below tilt threshold.
  • Failure: Plate tilts or leaves zone too soon, falls, exits workspace, or exceeds time limit.
Motor Learning Applications
  • Adaptation via Gain Perturbation: Virtual hand moves with scaled gain relative to real hand. Perturbation ramps up and down by phase.
  • Reinforcement Learning: Real-time visual feedback plus adaptive animations and sounds tied to success or failure.
  • Custom Feedback: Target color, bird behavior, and effects can change based on task outcome.
Builder

The MovementVR Builder is the GUI for designing your task. You can define all aspects of the experiment — from object positions to adaptation parameters — using an intuitive point-and-click interface. Over 500 parameters can be customized.

  • Main Builder Guide
  • Static Builder: Set constant parameters
  • Trial Builder: Define trial-by-trial changes
  • Parameter Catalog: Reference for editable parameters
  • Input Source Selection: Choose which hand is tracked, and what data is saved
  • CSV File Import: Upload custom parameter values
4. VR App
  • Download: Visit the MovementVR website and download the .apk for your VR headset (e.g., Meta Quest 2).
  • Install: Transfer the .apk to your device and install using standard sideloading procedures (step-by-step guide provided online).
  • Load experiment: Move the .csv file created with the Builder into the /MovementVR/Experiments folder on the headset.
  • Run the app: Open the MovementVR app and select your experiment from the list.
5. Analyzer

Use the MovementVR Analyzer to convert and examine data collected in the VR app.

a) Export & Conversion
  • Connect the headset to a PC and extract the .bin data files from internal memory.
  • Upload the .bin files to the Analyzer interface.
  • Click "Export" to convert them into standard .csv files.
b) CSV Structure
  • Columns: Time, hand positions (per joint), object positions, trial phase markers, success/failure, etc.
  • Rows: Each row represents a frame (i.e., one time point during the task).
c) MATLAB Analysis
  • Download MATLAB package: Zip file with scripts and example data provided on the Analyzer page.
  • Pipeline: Load converted CSV → Extract trial boundaries → Compute metrics like success rate and trajectory deviations.
  • Example scripts: Illustrative code provided for trial-by-trial plotting, computing adaptation curves, and visualizing hand trajectories.
