MovementVR Builder
Overview

The MovementVR Builder is the graphical interface for designing your VR motor learning experiment. You can customize most aspects of the task:

  • Lifting task parameters: the hands’ home position and conditions to start the trial, the plate’s starting position, the target position and success/failure criteria, workspace boundaries…
  • Motor learning features: magnitude and schedule of the gain perturbation for adaptation, and feedback visuals, sounds, and effects for reinforcement learning.
  • Game objects properties: Customize appearance and physics properties (size, color, animations, friction…) of bird, plate, target, and other game elements.
  • Hand Tracking & Data Recording: select unimanual or bimanual task, choose which kinematics to record…

You can choose whether each parameter is constant or if it varies across trials and phases in the experiment. Both options can be designed using our GUIs or by uploading values from a .csv file.

Getting started

To begin designing your experiment, click on the Builder tab in the top navigation menu. This will open the Main Builder Interface, your central workspace for defining the parameters of your MovementVR task.

The Main Builder Interface displays a grid of interactive elements — including game objects, task components, trial phases, and quick access buttons — each of which leads to specific configuration options.

You can click on any element or button in the Main Builder grid to edit its associated parameters. This opens a Static Builder window — your first point of contact for configuring both constant and trial-varying parameters.

For constant parameters, this window provides a straightforward form-like interface where you can directly enter or select values.

For trial-varying parameters, each parameter group includes a gear icon next to its label. Click the gear to indicate that the parameter should vary across trials. You’ll then be prompted to choose how to define those values:

  • Load: from a .csv file, or
  • Generate: using the Trial Builder interface.

Based on your selection, the appropriate interface will open — allowing you to define how the parameter changes across trials and phases in your experiment. These options are described in more detail in subsequent sections.
