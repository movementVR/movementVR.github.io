MovementVR

MovementVR is a platform designed to make it easy to create and run motor learning experiments in Virtual Reality — no coding required. You can design your experiment using a graphical interface, run it on a standalone VR headset, and process the collected data with provided tools.

This guide will walk you through each step: understanding the VR motor task (see MovementVR Task), designing your own experiment using the Builder, running it in the VR App, and processing the data with the Analyzer.
