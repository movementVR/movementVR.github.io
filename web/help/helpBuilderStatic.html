Builder Guide
Static Builder

When you can click on any element or button in the Main Builder Interface, this opens a Static Builder window to edit its associated parameters.

Steps to set a parameter

In the Static Builder, you can set the value of constant parameters (that you do not want to vary across trials). To edit a parameter, follow these steps:

  1. Click on the relevant game object or task component on the Main Builder page. If you're unsure where to find it, use the Parameter Catalog to search for its location (see Parameter Catalog help)
  2. This will open the Static Builder window, showing all parameters related to the selected game object or task component.
  3. Within the window, parameters are organized into Tabs, sorting the parameters by function (e.g., for editing an object appearance, position, feedback effects...). Browse the tabs to locate your desired parameter.
  4. Each Tab is a form‑like GUI with input fields.
    Each row contains a parameter "group" (e.g., an object position in X, Y, Z coordinates). Each row typically shows:
    • Name of parameter group (left column)
    • Editable input fields to define parameter values (middle column)
    • Icons to access help or advanced options for this parameter group (right column)
  5. Directly type or click‑to‑select the desired value for your parameter in the Editable input fields in the middle column
Icons and Expandable sections
  • Click the ? icon on the right to show the tooltip for your parameter - explaining what the parameter does and how to define its value correctly (e.g. the coordinate system, allowed values, etc...).
  • The Static Builder is also your first point of contact for configuring trial-varying parameters - this is done by the inline ⚙ icon on the right (see guide for setting parameters as “trial‑varying”).
  • Note that some tabs include expandable sections that reveal advanced or rarely used parameters when clicked
Footer Action Buttons

Action buttons at the bottom of the window apply to all parameters across all tabs within the current Static Builder window:

  • OK: Saves changes and closes Static Builder window.
  • Cancel / X: Closes window without saving.
  • Save: Saves changes but keeps window open to continue editing.
  • Help: Opens a popup with contextual help.

When you finish setting the parameters in the current Static Builder window, click OK to save them and return to the main MovementVR Builder interface.
