Builder Guide
Advanced Settings

You can configure any parameter to vary across trials and phases in your experiment.

To do so, click the ⚙ gear icon next to the parameter in the Static Builder interface (details below). You can import trial-by-trial parameter values from a .csv file, or generate sequences or schedules of parameter values using the Trial Builder GUI.

Steps for setting a parameter as “trial‑varying”

To set a parameter as trial‑varying:

  1. Click: on the relevant game object or task component in the Main Builder to open its Static Builder tab.
  2. Find: the parameter you want to vary, and click the gear icon next to it.
  3. Open: This action opens an Advanced Settings window.
  4. Select: the checkbox(es) for the parameter(s) that you wish to set as trial‑varying (e.g., just X, or X and Z, etc.).
    • Most times, you will select the subset of parameters that you want to vary trial-by-trial, and unselect parameters that you want to keep constant.
    • You can also select and configure one trial-varying parameter at a time - this is sometimes needed if you want the parameters to vary independently of each other. See example below.
  5. Choose method: decide how to define the trial‑varying values. You will choose from three available "Input Source" options:
    • Static Builder (default): Keep the parameter value constant across all trials. Editing continues in the original Static Builder window.
    • Trial Builder: Use a graphical interface to define trial-by-trial values. This opens the Trial Builder where you can configure sequences and conditions. Recommended for configuring new experiments.
    • File: Load values from a CSV file. Recommended when reusing pre-generated parameter sets, or if you prefer coding or the desired behavior is not available in Trial Builder.
  6. Chosen interface opens: you will be redirected to the chosen interface (Trial Builder or File Import) - to edit the selected parameter(s) only
    • If you changed the input source method, any values previously defined using a different method will be lost for the selected parameters.
  7. Upon return to Static Builder: When you define a parameter using advanced options (via the ⚙ gear icon), it is disabled and no longer editable through the Static Builder. To revert back, click the ⚙ icon again and select the Static Builder option.
    • Setting any gain mangitude parameter with Trial Builder or File also disables the Perturbation Schedule parameters in Static Builder (i.e. the ones defining the number of trials in baseline, adaptation... used to automatically vary gain across trials)
Example: vary Target Position across trials

Sample case scenario:You are editing the position of a target object.

You want the target to:

  • appear at different heights across trials
  • appear at different lateral positions across trials
  • always remain at the same depth, 0.5 meters in front of the participant

To start, you do these steps in the Static Builder:

  • set Z (depth / position in front) = 0.5 meters in the Static builder
  • click on the gear icon for the parameter group, which contains X (lateral position), Y (height), and Z (depth / position in front)
Three examples for how you proceed next
  • Example 1: You want to define X & Y together using Trial Builder — for example, by randomly drawing X–Y position pairs from a predefined list:
    1. Step 1: select checkboxes for X and Y, and unselect Z
    2. Step 2: choose Trial Builder to configure X and Y together.
  • Example 2: You want to define X & Y separately using Trial Builder — for example, by randomly drawing X and Y independently from separate lists:
    1. Step 1 for X: select checkbox for X, and unselect Y and Z
    2. Step 2 for X: choose Trial Builder to configure X.
    3. Re-open this popup: re-click the gear icon for this parameter group (from the Static Builder)
    4. Step 1 for Y: select checkbox for Y, and unselect X and Z
    5. Step 2 for Y: choose Trial Builder to configure Y.
  • Example 3: You want to define X using Trial Builder & X using File:
    1. Step 1 for X: select checkbox for X, and unselect Y and Z
    2. Step 2 for X: choose Trial Builder to configure X.
    3. Re-open this popup: re-click the gear icon for this parameter group (from the Static Builder)
    4. Step 1 for Y: select checkbox for Y, and unselect X and Z
    5. Step 2 for Y: choose File to upload Y values from .csv file.
