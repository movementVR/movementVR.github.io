Analyzer

Use the MovementVR Analyzer to convert and examine data collected in the VR app.

Export & Conversion
  • Connect the headset to a PC and extract the .bin data files from internal memory.
  • Upload the .bin files to the Analyzer interface.
  • Click "Export" to convert them into standard .csv files.
CSV Structure
  • Columns: Time, hand positions (per joint), object positions, trial phase markers, success/failure, etc.
  • Rows: Each row represents a frame (i.e., one time point during the task).
MATLAB Analysis
  • Download MATLAB package: Zip file with scripts and example data provided on the Analyzer page.
  • Pipeline: Load converted CSV → Extract trial boundaries → Compute metrics like success rate and trajectory deviations.
  • Example scripts: Illustrative code provided for trial-by-trial plotting, computing adaptation curves, and visualizing hand trajectories.
