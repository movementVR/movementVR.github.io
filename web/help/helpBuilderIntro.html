Builder Guide

This guide walks you through designing your MovementVR task and experiment. It will explain how to:

  • Configure the different aspects of the app - game objects, task parameters, motor learing components...
  • Create experimental phases and trial-by-trial variations for any parameters you want to vary across trials

You can customize most aspects of the task, such as:

  • Lifting task parameters: the hands’ home position and conditions to start the trial, the plate’s starting position, the target position and success/failure criteria, workspace boundaries…
  • Motor learning features: magnitude and schedule of the gain perturbation for adaptation, and feedback visuals, sounds, and effects for reinforcement learning.
  • Game objects properties: Customize appearance and physics properties (size, color, animations, friction…) of bird, plate, target, and other game elements.
  • Hand Tracking & Data Recording: select unimanual or bimanual task, choose which kinematics to record…

You will learn two ways to design your experiment:

  • using our coding-free GUIs
  • importing from .csv file

This guide assumes you are familiar with the MovementVR Motor Task - if not, please return to the main Help page and review the Motor Task guide.
