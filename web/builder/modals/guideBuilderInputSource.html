Builder Input Source Help Guide

×
1. Overview

When you click the ⚙ gear icon next to a parameter group in the Static Builder, this popup appears to let you choose how that parameter should be defined. These advanced options are only needed if you want the parameter to vary across trials instead of remaining constant.

2. Explanation of Step 1 & Step 2

The popup has two main steps:

Step 1: Select Parameters

Use the checkboxes to select which specific parameters in this parameter group you want to edit using advanced options (e.g., just X, or X and Z, etc.).

  • Most times, you will select the subset of parameters that you want to vary trial-by-trial, and unselect parameters that you want to keep constant.
  • You can also select and configure one trial-varying parameter at a time - this is sometimes needed if you want the parameters to vary independently of each other. See "example" below.

Step 2: Choose Method

Choose the method used to define the parameter values across trials. This is called selecting the Input Source. There are three available options:

  • Static Builder (default): Keep the parameter value constant across all trials. Editing continues in the original Static Builder window.
  • Trial Builder: Use a graphical interface to define trial-by-trial values. This opens the Trial Builder where you can configure sequences and conditions.
  • File: Load values from a CSV file. Recommended if you prefer coding, if the desired behavior is not available in Trial Builder, or when reusing pre-generated parameter sets.
3. "Continue" and what happens next

What happens after clicking Continue:

  • You will be redirected to the interface for the selected method (Static Builder, Trial Builder, or CSV file upload).
  • If you changed the input source method, any values previously defined using a different method will be lost for the selected parameters.
  • If you selected Trial Builder or File, the selected parameter(s) will be disabled in the Static Builder window.
    If you change your mind, reopen this popup via the ⚙ icon and reselect Static Builder.
4. Example

Sample case scenario:You are editing the position of a target object. You want the target to appear at different heights and lateral positions across trials, but always remain 0.5 meters in front of the participant.

You set Z (depth / position in front) = 0.5 meters in the Static builder. Then, you click on the gear icon for the parameter group, which contains X (lateral position), Y (height), and Z (depth / position in front).

→ Example 1: You want to define X & Y together using Trial Builder — for example, by randomly drawing X–Y position pairs from a predefined list:

  1. Step 1: select checkboxes for X and Y, and unselect Z
  2. Step 2: choose Trial Builder to configure X and Y together.

→ Example 2: You want to define X & Y separately using Trial Builder — for example, by randomly drawing X and Y independently from separate lists:

  1. Step 1 for X: select checkbox for X, and unselect Y and Z
  2. Step 2 for X: choose Trial Builder to configure X.
  3. Re-open this popup: re-click the gear icon for this parameter group (from the Static Builder)
  4. Step 1 for Y: select checkbox for Y, and unselect X and Z
  5. Step 2 for Y: choose Trial Builder to configure Y.

→ Example 3: You want to define X using Trial Builder & X using File:

  1. Step 1 for X: select checkbox for X, and unselect Y and Z
  2. Step 2 for X: choose Trial Builder to configure X.
  3. Re-open this popup: re-click the gear icon for this parameter group (from the Static Builder)
  4. Step 1 for Y: select checkbox for Y, and unselect X and Z
  5. Step 2 for Y: choose File to upload Y values from .csv file.
