1. Overview

The Parameter Catalog provides a searchable reference table listing all parameters available across the Builder interface. It is useful for verifying parameter labels, checking where parameters appear in the UI, and preparing valid CSV files.

Click Parameter Catalog on the main Builder page to launch this table.

2. Table Columns
  • Code Name: Internal identifier used in CSV files (scriptName,paramName format).
  • UI Location: How to navigate to the parameter in the Builder (element in Main Builder Grid → tab in Static Builder; e.g., Target → Visual Mesh).
  • Display Label: How the parameter is shown to the user in the Static Builder interface (e.g., Size [m]: → Width).
  • Type: Input type and any constraints (e.g., number (min=0, max=1) or checkbox (values: TRUE, FALSE)).
  • Description:Description of the parameter group this parameter is part of.
3. View Modes

The toggle buttons above the table control whether duplicate entries are shown:

  • All Builder Locations: Shows each parameter as many times as it appears in the Builder. This includes duplicates when the same parameter is editable from multiple buttons or links.
  • Unique Parameters: Shows each parameter only once, with all its Builder locations merged into a single line.

Use the Unique Parameters mode when preparing a clean list of variables for CSV files.

4. Exporting as CSV

Click Download as CSV to export the current view (either all locations or unique parameters) to a .csv file.

This file contains the same four columns shown in the table. It can be used to reference valid scriptName,paramName pairs, check type constraints, or build your own parameter import files.

5. Example Use: Preparing a CSV File

When importing parameters via the File method (⚙ icon → File), you must use the correct scriptName,paramName combination. These are found in the Code Name column.

Sample structure: 


  scriptName  , paramName              , trial1 , trial2 , trial3
  setupScript , tgtBirdPositionOffsetX , 0.1    , 0.2    , 0.3
  setupScript , tgtBirdPositionOffsetY , 0.2    , 0.2    , 0.25
  setupScript , tgtBirdPositionOffsetZ , 0.5    , 0.5    , 0.5
  • The first two columns identify the parameter.
  • Each additional column defines values for a trial.
  • Use one value and leave other columns blank to define a constant.
