1. Overview

The Import Parameters from CSV popup appears when you choose File as the input source for one or more parameters via the ⚙ gear icon. It allows you to upload a CSV file and assign parameter values based on its contents.

The imported values can define trial-by-trial sequences or constant values, depending on the parameter type and file structure. This tool is ideal for researchers who prefer coding or wish to reuse previously generated configurations.

2. Step-by-Step Instructions

Step 1: Upload File

Click Choose File to upload your .csv file. Once uploaded, the filename and a “Loaded!” message confirm that the file has been read.

Step 2: Select Parameters

Choose whether to import values for:

  • Selected parameters only: Use this option to import only the specific parameters for which you initiated the File input source. The list of parameters appears next to the radio button.
  • All parameters in file: This imports all parameters found in the CSV (helpful when loading a pre-made full task configuration).

Step 3: Review Method for Constant Parameters

If your file includes parameters with a single constant value (not trial-by-trial), choose how they should be handled:

  • Keep Method as "File" (default): These values remain read-only and are still shown in Static Builder, but cannot be edited there.
  • Convert Method to "Static Builder": The constant value is copied into the Static Builder and becomes editable there.
3. CSV Format

A valid CSV file should follow this structure:


  scriptName  , paramName              , trial1 , trial2 , trial3
  setupScript , tgtBirdPositionOffsetX , 0.1    , 0.2    , 0.3
  setupScript , tgtBirdPositionOffsetY , 0.2    , 0.2    , 0.25
  setupScript , tgtBirdPositionOffsetZ , 0.5    , 0.5    , 0.5
...
  • The first two columns together (scriptName and paramName) identify the parameter.
  • Each following column represents a trial. The number of columns determines the number of trials.
  • If a value is constant across all trials, you can write a single value in column 3 and leave subsequent columns blank.
  • A file can contain a mix of constant and trial-varying definitions.

Parameter Catalog: Click "Parameter Catalog" on the main Builder page to access a list of all parameters with their scriptName and paramName, location in the Builder UI, definition and allowed values.

5. Finalizing Import

After selecting your options, click OK to complete the import and return to the Static Builder interface. The imported parameters will now appear with a "File" tag and be disabled for editing unless converted.

Click Cancel to exit without making changes.
