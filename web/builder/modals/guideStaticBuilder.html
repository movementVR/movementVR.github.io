Static Builder Help Guide

×
1. Overview

The Static Builder lets you define constant values for task parameters that do not change across trials.

This is the default interface when clicking on an object or button in the main MovementVR Builder GUI.

2. Accessing the desired parameters

The content of each Static Builder window depends on what you click. Each object or button in the main MovementVR Builder page opens a different window for editing a unique set of parameters specific to that item:

  • Game Objects buttons(e.g., plate, bird...shown in the main grid): edit all parameters related to that object, such as appearance, position, and task-relevant behaviors.
  • Trial Sequence buttons (Edit Transitions, Edit Instructions in the top row): configure how the trial unfolds (e.g. intertrial interval, "home" conditions to start the trial, success/failure criteria...) or participant instructions.
  • Quick Links: shortcuts to frequently used parameters grouped by topic (e.g., adaptation, data collection). These access (and may override) some of the same parameters as object-specific windows.
3. Static Builder organization

Each Static Builder window is organized into multiple tabs, sorting the parameters by function (e.g., for editing an object appearance, position, feedback effects...).

Within each tab, each row contains a parameter "group" (e.g., an object position in X, Y, Z coordinates). Each row typically includes:

  • Name of parameter group (left column)
  • Editable input fields to define parameter values (middle column)
  • Icons to access help or advanced options for this parameter group (right column)

Some tabs include expandable sections that reveal advanced or rarely used parameters when clicked.

3. Icons & action buttons

Inline icons (right column of each row) provide tools specific to that parameter group:

  • ⚙ (gear icon): advanced options to set parameter values that are not constant but vary trial-by-trial (uploaded as .csv file or defined using Trial Builder interface)
  • ? (question mark icon): tooltip explaining the specific parameters and how to set them (e.g. units, coordinate system...).

When you define a parameter using advanced options (via the ⚙ gear icon), it is disabled and no longer editable through the Static Builder. To revert back, click the ⚙ icon again and select the Static Builder option.

Action buttons at the bottom of the window apply to all parameters across all tabs within the current Static Builder window:

  • OK: Saves changes and closes Static Builder window.
  • Cancel / X: Closes window without saving.
  • Save: Saves changes but keeps window open to continue editing.
4. Finish and export

When you finish setting the parameters in the current Static Builder window, click OK to save them and return to the main MovementVR Builder interface.

When you have set all the desired parameters, click Download on the main MovementVR Builder page to export all parameters to .csv file.

The .csv file contains both static and trial-varying parameters and is used by the MovementVR application to apply your configured task structure during runtime. It must be transferred to the headset for use - see "Run Experiment" for instructions.
