1. Overview

The Main Builder Interface is your starting point for designing tasks in MovementVR. From here, you can click on different game objects or buttons. This will open a UI to edit the associated parameters.

The first window you will open is called Static Builder Interface. There, you can define constant parameters or click additional buttons to open other interfaces for advanced options.

Help on the different buttons and interfaces will be provided as you go along. You can also open the different guides here: Static Builder Guide, Input Source Popup, Trial Builder Guide, and CSV File Import Guide.

2. Trial Sequence

The top row of the interface shows the Trial Sequence — a set of labeled columns representing the different "phases" of a single trial:

  1. intertrial: pause between trials (also called intertrial interval)
  2. home position: participant moves hands to start location
  3. plate contact: plate has appeared - waiting for participant to make contact with the plate and begin lifting it
  4. plate lift: participant is lifting the plate
  5. feedback: plate lift has ended (target reached, plate fell or else) - visual or auditory feedback about success, error, or movement is given
  6. break: optional resting break between selected trials

Use the buttons to the right to edit parameters related to Trial Sequence:

  • Use Edit Transitions to configure when and how phases change during a trial (e.g., timing, success/failure conditions, etc.).
  • Use Edit Instructions to customize participant messages shown during phases.
3. Game Objects

The left column of the interface shows the main game objects and task components:

  • Reinforcement: Objects/effects related to success/failure feedback
  • Bird: Virtual bird object that moves and lands on the target
  • Target: The target for the participant to reach (functional + visual representation)
  • Plate: The object the user lifts as part of the motor task
  • Hand Home: Settings for the hand's starting (home) position
  • Hands & Perturbation: Hand tracking and adaptation perturbation
  • Workspace: Spatial boundaries defining the allowed environment for the plate

Each row of the table corresponds to a game object or logical task component. The horizontal colored bars indicate when each object is active during different trial phases.

Click on an object or component to customize their appearance, position, task behavior, etc...

4. Quick Links

The right side of the Main Builder includes Quick Links — buttons that open commonly used parameter sets grouped by experimental topic:

  • Reaching Task: common reaching task parameters, including home & starting position, target position and success criteria...
  • Motor Adaptation: perturbation magnitude and schedule
  • Reinforcement: feedback visuals/sounds/effects to convey success or failure
  • Paradigm: overall paradigm start & end (messages/delays), trial number display, paradigm phases...
  • Kinematics: hand tracking and data recording options
4. Footer Action Buttons

Below the main grid with Game Objects, you find action buttons to perform actions related to all parameters:

  • Download: After completing your configuration, click Download to export all parameter values to a .csv file used at runtime on the headset - see "Run Experiment" for instructions.
  • Upload Parameters: Load all parameters from a .csv file. CSV upload is described in this guide: CSV File Import Guide. However, the Upload Parameters button on the main page uploads ALL parameters defined in the file, and loads any constant values into the Static Builder for editing (in constrast to the gear icon described in the guide where you can choose)
  • Save / Load Session: store or load the full configuration for a Builder session. This includes Input Sources for all parameters and, when applicable, the Trial Builder setup (the UI configuration rather than parameter values - e.g., if a parameter is drawn at random from list, it stores the list and rules for randomization rather than drawn values). The session configuration can be stored in your internal browser memory or exported to .json file.
  • Parameter Catalog: opens a searchable table listing all Builder parameters. Use this to look up variables when preparing CSV files or checking how each field is labeled in the UI. The table contains the following parameter properties:
    • Code Names: internal way parameters must be specified in the csv file used to load parameters from file
    • UI Location: Static Builder window and tab where the parameter is found
    • Display Label: name and label as shown in the Static Builder
    • Type: data type including explanation of the allowed values
